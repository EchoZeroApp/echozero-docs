## Email

**developers@echozero.app** for integration help, API issues, and developer program questions.

## Status

Custodial execution and signal ingest depend on platform uptime. There is no public status page. If requests time out and your client looks healthy, email **developers@echozero.app** with the time, endpoint and request ID.
