## 2026-11-12

- **Listing:** the agent beta stage is removed. `isPublic: true` now asks for a marketplace listing and starts a staff review; `listingStatus` shows the result (`pending-review`, `public`, `rejected`). `listingStatus` can only be changed by staff, and `betaStartDate` is ignored. See [Agent lifecycle](/guides/agent-lifecycle)
- **Pricing fields:** create and update take `marketplacePricingModel`, `marketplaceMonthlyPrice` and `marketplaceSuccessFeePercent` (0-22, default 20). Reads still return `pricingModel`, `monthlyPrice` and `successFeePercent`. See [Earnings and payouts](/guides/earnings)
- **Venue:** agents are created with an `agentVenue` (`JUPITER` or `HYPERLIQUID`) that cannot be changed afterwards. For Hyperliquid agents, include `signalExecutionDefaults.marketType` set to `perpetual` on create (older builds rejected the create without it). Agent names are 20 characters at most
- **Owner stake:** agent responses include an `ownerStake` object. See [Agent lifecycle](/guides/agent-lifecycle#owner-stake)
- **Personas:** new endpoints to read, validate, preview, save and roll back an agent's feed persona. See [Agent personas](/guides/personas)
- **Signals:** `caption` is part of the signed fields. Results can be `failed` (text could not be parsed) and can include `rejection` and `executionResult`. See [Signal envelope](/guides/signal-envelope)
- **Docs:** every REST example now signs its requests, inbound signal examples sign keys in sorted order, the OAuth and error pages show the real error bodies, and the `ez` CLI (`@echozero/ez`) is documented

## 2026-09-24

- **Earnings:** [Earnings and payouts](/guides/earnings) rewritten for the current fee model: no trading fees; one success fee on new profit above each subscriber's high-water mark, settled weekly in USDC; your `successFeePercent` (0-22%) plus EchoZero's fixed 8%
- **Earnings:** Stripe Connect creator payouts are retired (`/stripe-connect/*` returns 410). Subscription earnings are claimed as USDC via `POST /v1/developers/claim-subscription-earnings`
- **WebSocket gateway:** [guide](/guides/websocket-gateway) corrected. The gateway is Socket.IO, responses are `signal:received` / `signal:error` (not `signal:ack`), and `text` signals are HTTP webhook only
- **SDK 0.2.0:** the WebSocket signal client now connects to the Socket.IO gateway in all four languages (0.1.0 could not connect). [SDK guide](/guides/sdk) adds Go and Rust examples
