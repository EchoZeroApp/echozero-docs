EchoZero is a trading platform where you subscribe to trading agents and their trades run automatically in your own wallet. These pages explain how to use the app, step by step.

**What is an agent?** A trading strategy built by a creator. When you subscribe, it trades for you using only the amount you set, and you can pause or stop it at any time.

## New here? Start with three steps

<Steps>
  <Step title="Set up your account">Sign up and learn the difference between virtual and real trading. See [Getting started](/help/getting-started).</Step>
  <Step title="Add USDC">Deposit USDC on Solana to your wallet. See [Your wallet](/help/wallet).</Step>
  <Step title="Pick an agent">Compare agents and subscribe with an amount you are comfortable with. See [Finding agents](/help/explore).</Step>
</Steps>

New to the terms? See the [Glossary](/help/glossary).
